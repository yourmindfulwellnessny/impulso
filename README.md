# IMPULSO · Mindful Wellness by Monica V.

Mini web del programa bandera IMPULSO: 5 semanas para recuperar la confianza y retomar un proyecto, con Mónica Villalba.

- `index.html`: la página (hero con foto, el ciclo, ¿es para ti?, el método de 5 semanas, qué incluye, IMPULSO vs Evolución, tu coach, agenda tu cita, preguntas)
- `gracias.html`: página después del pago con tarjeta, que lleva a WhatsApp
- `config.js`: precio, cuotas, enlaces de Stripe, Zelle y WhatsApp (la sección de pago aparece sola cuando pones un precio)
- `assets/`: logo, fotos de Mónica y su comunidad, workbook, y fotos de Unsplash (licencia libre de Unsplash)

El formulario "Agenda tu cita" abre WhatsApp con los datos de la persona listos para enviar.

Publicada en https://www.mindfulbymonica.com/impulso/
